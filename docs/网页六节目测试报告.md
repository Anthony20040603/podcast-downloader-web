# 六个播客的网页兼容测试

测试范围：Apple 中国区搜索回调、RSS 解析、每个节目首个可用音频的 1 KB 小片段。没有下载整期音频。

以下为接口测试；浏览器安全策略阻止自动检查 file:// 页面，未验证实际点击保存。

飞驰圈的 Apple 搜索标题为「飞驰圈 | F1复盘」。

入夜电波、朋嗑儿的 RSS 与音频可以由本地程序访问，但网页 fetch 无法跨站读取；导入 RSS 可显示节目列表，音频仍需通过「打开音频」在原站保存，或使用桌面版。部署 GitHub Pages 不会解除来源的跨站限制。

已修正：使用 Apple 官方 JSONP 跨站搜索回调，添加中国区参数；喜马拉雅 RSS 改用已验证可访问的 HTTPS 地址；来源返回空 RSS 时显示明确提示。

代码校验：脚本语法、六组真实搜索返回的回调处理与清理、取消请求均通过。
